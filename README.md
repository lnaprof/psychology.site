# psychology.site

Лендинг психолога/коуча «Анна Соколова» — демонстрационный портфолио-проект.
Современный адаптивный одностраничник на стыке доказательной психологии (КПТ, ACT, CBT-I)
и коучинга (ICF) с измерением прогресса в цифрах. Восемь блоков, форма заявок
на Яндекс.Форме, SEO-разметка, низкий LCP.

## Форма заявок

В секции «Запись» встроена Яндекс.Форма (iframe):

`https://forms.yandex.ru/cloud/6ab3f55be010db0855889fbd`

Ответы приходят в аккаунт владельца формы; уведомления о новых заявках
настраиваются на forms.yandex.ru.

## Как проверить локально

Просто откройте `index.html` в браузере двойным кликом — анимации, меню, FAQ
и скроллы работают без сервера. Для чистого теста можно поднять локальный сервер:
`python -m http.server 8765` — сайт на `http://127.0.0.1:8765/`.

## Тон и правила (по бренду)

- Личное обращение «ты» — только в первом экране (по утверждённому копирайту),
  остальные блоки — «вы».
- Во всех текстах сайта используется «е» вместо «ё».
- Фото: только предоставленные снимки, без стоковых поз. Все фото — собирательные образы.

## Ограничения

- Заявки собирает Яндекс.Форма — интеграция с бэкендом не требуется.
- Конфиденциальность: данные формы используются только для связи по запросу,
  третьим лицам не передаются.
